# FB-028a — Navigation: die restlichen Dashboard-Seiten gruppiert

**Was:** Die vier Dashboard-Seiten ohne Navigationsgruppe (API-Zugänge, Käufer-Profil,
Leads, Marktplatz) haben jetzt eine, und alle Gruppen sind im Panel in einer sinnvollen
Reihenfolge registriert.

**Warum:** Nachtrag zu FB-028. Eine Seite ohne Gruppe hängt in Filament unsortiert
zwischen den Gruppen — sie ist da, aber nicht dort, wo man sie sucht. Genau das Muster,
das die Funnel-Vorlagen unauffindbar gemacht hat, nur eine Ebene tiefer.

**Neue Config-Keys:** keine.

**Migrationen:** keine.

Die Reihenfolge folgt dem Tenant-Typ: **Funnels** und **Leads** für Betreiber, darunter
**Marktplatz** für Käufer, dann **Workspace** (API-Zugänge) und **Team Management**.

Zwei Kleinigkeiten nebenbei:

- Der Panel registrierte bislang eine Gruppe `Team`, während die Users-Seite
  `Team Management` trägt. Die registrierte Gruppe wurde deshalb nie verwendet und die
  Sortierung griff für Users nicht. Jetzt stimmen beide überein.
- Das Audit-Log bleibt bewusst unter „Settings". Es ist keine Einstellung, aber auch
  keinem der neuen Bereiche zuzuordnen — es protokolliert quer über Login, Mandantenwechsel,
  Rollen, API-Tokens und Lead-Kauf. Eine eigene Gruppe mit einem einzigen Eintrag wäre
  mehr Rauschen als Ordnung.

**Tests:** keine, Navigation ist nach Abschnitt 8 testfrei. Serverseitig verifiziert, dass
das Dashboard sowohl für einen Betreiber- als auch für einen Käufer-Mandanten rendert.
