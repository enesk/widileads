# FB-028e — Rauchtest je Panel, und zwei Fallstricke im Leitfaden

**Was:** Drei Rauchtests, die belegen, dass Admin-Panel und Tenant-Dashboard überhaupt
laden. Dazu zwei Präzisierungen im Leitfaden.

**Warum:** In FB-028 haben zwei Fehler nacheinander *jede* Seite eines Panels mit 500
lahmgelegt, und `composer check` blieb beide Male grün — kein Test der Suite hat je eine
Seitenleiste gerendert. Gefunden hat beide ein Mensch, der die Seite aufgerufen hat.

**Neue Config-Keys:** keine.

**Migrationen:** keine.

## Die Tests

`tests/Feature/Funnel/PanelSmokeTest.php`, drei Fälle: Admin-Panel, Dashboard eines
Betreiber-Mandanten, Dashboard eines Käufer-Mandanten. Anmelden, Seite aufrufen, 200
erwarten — sonst nichts. Keine Bezeichnungen, keine Reihenfolge, keine Struktur.

Gegengeprüft gegen beide echten Fehler: Ein Icon an einer Gruppe, deren Einträge
ebenfalls Icons haben, macht den Betreiber-Fall rot; `__('Leads')` als Gruppenname
ebenso, mit `getNavigationGroup(): Return value must be of type ?string, array
returned`. Der Käufer-Fall bleibt dabei grün — er sieht die Leads-Gruppe nicht.

## Leitfaden

**Abschnitt 8** bekommt die Präzisierung „Erreichbarkeit ist kein Aussehen": Der
Ausschluss von UI-Rendering meint Beschriftungen, Reihenfolge, Struktur, Markup. Eine
Seite, die mit 500 gar nicht mehr lädt, ist kein Aussehen, sondern Totalausfall. Je
Panel ein Rauchtest, alles darüber hinaus bleibt testfrei.

**Abschnitt 12** ist neu und beschreibt die beiden Fallstricke, damit sie nicht ein
drittes Mal auftreten:

- Ein Übersetzungsschlüssel ohne Punkt (`__('Leads')`) wird von Laravel als Dateiname
  gedeutet und trifft auf einem Dateisystem ohne Groß-/Kleinschreibung — macOS — unsere
  `lang/de/leads.php`. `__()` liefert dann ein Array, `getNavigationGroup(): ?string`
  wirft einen TypeError. Auf Linux nicht. Ein Fehler, der lokal auftritt und in der CI
  nicht, ist der unangenehmste Typ, den wir haben.
- Filament lässt Icons entweder an der Navigationsgruppe oder an ihren Einträgen zu,
  nicht an beidem. Die SaasyKit-Gruppen umgehen das nur, weil sie `collapsed()` sind.

Der Backlog-Eintrag „Die Testsuite rendert die Dashboard-Navigation nie" ist damit als
erledigt markiert.
