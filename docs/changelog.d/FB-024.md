# FB-024 — JS-Embed-Snippet

**Was:** `public/embed/v1.js` (Vanilla-JS, 4,8 kB unkomprimiert, 1,8 kB gzip, kein
Framework) bettet eine Funnel-Strecke als iFrame in fremde Webseiten ein — wahlweise
inline oder als Overlay mit Trigger-Button. Die Höhe wird per `postMessage` gemeldet und
vom Snippet übernommen. Dazu die Testseite `GET /dev/embed-test` (nur lokal) und die
Schnittstellenbeschreibung in
[embed-schnittstelle.md](../funnel-builder/embed-schnittstelle.md).

**Warum versioniert unter `/embed/v1.js`:** Die URL steht im Quelltext fremder Seiten,
auf die wir keinen Zugriff haben. v1 wird deshalb nur erweitert, nie verändert;
Unverträgliches bekommt eine v2 unter eigener URL, und v1 bleibt dauerhaft erreichbar.
Der vollständige Vertrag — `data-`Attribute und Nachrichtentypen — steht in der
Schnittstellenbeschreibung.

**Sicherheit der Nachrichten:** Das iFrame sendet gezielt an den `origin` der
einbettenden Seite, nie an `*` — sonst könnte jede Seite mitlesen, die das iFrame in ein
eigenes einbettet. Das Snippet verarbeitet umgekehrt nur Nachrichten, deren
`event.origin` zur Plattform gehört, deren `event.source` das eigene iFrame ist und
deren `source`, `version` und `token` stimmen; ohne diese Prüfung könnte jede beliebige
Seite die iFrame-Höhe fernsteuern.

**Keine zweite Ansicht:** Die Strecke läuft im vorhandenen Layout aus FB-020. `?embed=1`
schaltet lediglich Seitenhintergrund und Außenabstände ab und aktiviert die
Höhenmeldung.

**Vorbereitet für FB-025:** `App\Funnel\Runtime\EmbedOriginPolicy` normalisiert den
mitgegebenen Origin und entscheidet über die Einbettung — heute erlaubt sie jede
Herkunft. FB-025 wertet dort `funnel_origins` aus; die Runtime muss dafür nicht
angefasst werden.

**Neue Config-Keys:** keine. **Migrationen:** keine.
